Challenge

신규 공용 스킨 제작 시 캐릭터별 재스킨, 추가 세팅, 파일 관리 및 업로드 과정이 대부분 수작업으로 진행되고 있었습니다.

캐릭터 수가 증가할수록 반복 작업이 증가했고, 휴먼 에러와 품질 편차가 지속적으로 발생했습니다.

기존 작업 프로세스

신규 스킨 생성 → 캐릭터별 재스킨 → 추가 세팅 → 파일 관리 → 업로드

Solution

레퍼런스 리깅 파일을 기반으로 신규 캐릭터용 공용 스킨 파일을 자동 생성하는 Auto-Fit 파이프라인을 구축했습니다.

주요 기능

  • 공용 스킨 자동 생성
  • Auto-Fit 자동 처리
  • 스킨 데이터 자동 복사
  • 네이밍 규칙 검증
  • 파일 구조 검증
  • 작업 파일 자동 관리

개선된 작업 프로세스

Auto-Fit 실행 → 자동 생성 → 자동 검증 → 최종 확인

Result

  • 제작 시간 약 50% 단축
  • 반복 수작업 제거
  • 휴먼 에러 감소
  • 작업 품질 표준화
  • 대량 제작 대응 효율 향상
