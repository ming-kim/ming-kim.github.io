SmartRef 전환 및 데이터 최적화

6,000개 이상의 애니메이션 데이터를 SmartRef 구조로 전환한 프로젝트

프로젝트 개요

SmartRef 도입 검증부터 자동화 툴 개발, 운영 가이드 작성까지 수행하며 대규모 애니메이션 데이터를 전환한 프로젝트입니다.

담당 업무

  • SmartRef 도입 검증
  • XRef 비교 분석
  • 자동화 툴 개발
  • 대량 변환 작업 수행
  • 운영 가이드 작성

문제점

기존 데이터 구조의 관리 비용 증가와 저장 공간 사용량 증가 문제가 있었습니다.

해결 방법

SmartRef 구조 검증 후 자동화 툴을 개발하여 대량 변환 작업을 안정적으로 수행할 수 있도록 구축했습니다.

성과

  • 약 6,000개 애니메이션 데이터 전환
  • 약 30GB 저장 공간 절감
  • 운영 효율 향상
  • 작업 프로세스 표준화

사용 기술

3ds Max / Python / SmartRef / Asset Management
