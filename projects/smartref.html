Challenge

기존 애니메이션 파일은 리그와 모델 데이터를 각각 포함하고 있어 데이터 중복 저장이 발생하고 파일 관리 비용이 증가하고 있었습니다.

또한 리깅 구조가 변경될 경우 다수의 애니메이션 파일에 영향을 주어 유지보수와 버전 관리에 어려움이 있었습니다.

  • 데이터 중복 저장
  • 파일 용량 증가
  • 리그 변경 시 재작업 발생
  • 버전 관리 복잡도 증가

Solution

SmartRef 기반 참조 구조를 도입하여 리그 데이터와 애니메이션 데이터를 분리하는 제작 파이프라인을 설계했습니다.

기술 검증

  • Override 구조 검증
  • Reload 동작 검증
  • Constraint 안정성 검증
  • Morpher 유지 검증
  • Export 안정성 검증

  • 애니메이션 데이터 유지 컨버팅
  • 버전 및 경로 관리 툴

파이프라인 구축

  • Body / Head 자동 조립
  • Reference 자동 연결
  • Perforce 연동 자동화
  • 배치 처리 지원

  • SmartRef 적용 가능성 검증 완료
